I developed a deep-learning classifier to detect malware patterns using a convolutional neural network. The project reached **96% accuracy**.

**Technologies:** CNN, TensorFlow, Deep Learning

### Nutrition Detection with Computer Vision

I worked on a computer-vision system to detect food items and nutritional values in images. The project used YOLOv8 and reached **92% accuracy**.

**Technologies:** YOLOv8, Computer Vision

### Agentic AI and RAG Conversational Assistant

I worked on a LangChain conversational agent with vector memory, Chain-of-Thought and few-shot prompting, and model fine-tuning.

**Technologies:** LangChain, RAG, Vector Memory, LLMs
