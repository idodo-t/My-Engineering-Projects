# Engineering Projects

This repository is an index only. Each project has its own public repository so recruiters can open the code directly without duplicate copies in this catalog.

The eight reference implementations were created from project summaries. They are not presented as recovered original source code and do not reproduce unavailable datasets, weights, or historical metrics. Each repository README explains its scope and prerequisites.

## Artificial Intelligence

- [Malware Detection with CNN](https://github.com/idodo-t/malware-detection-cnn) — CNN training and prediction pipeline; requires the original feature dataset.
- [Nutrition Detection with YOLOv8](https://github.com/idodo-t/nutrition-detection-yolov8) — detection pipeline; requires labeled images and annotations.
- [Agentic RAG Assistant](https://github.com/idodo-t/agentic-rag-assistant) — local document retrieval, source attribution, session memory, and optional LLM generation.

## Data and Connected Systems

- [Hotel Occupancy Forecast](https://github.com/idodo-t/hotel-occupancy-forecast) — time-series baseline with clearly synthetic demo data.
- [BI / ETL Data Warehouse](https://github.com/idodo-t/bi-etl-data-warehouse) — validated CSV-to-SQLite ETL and local dashboard.
- [Real-Time IoT Dashboard](https://github.com/idodo-t/iot-mqtt-dashboard) — MQTT subscriber, JSON API, and browser dashboard.

## Software Engineering and Security

- [Library Management System](https://github.com/idodo-t/library_management_system) — original Flask and MongoDB source for books, members, loans, and statistics.
- [Linux Server Hardening](https://github.com/idodo-t/linux-server-hardening) — read-only audit for selected SSH settings and account-file permissions.
- [Medical Appointment Booking API](https://github.com/idodo-t/medical-appointment-booking) — local .NET demo with JSON storage and appointment conflict checks; not a production medical system.
